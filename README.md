# ReShade CRT Royale

ReShade CRT Royale mod for 7th Heaven/Junction VIII

# Special thanks

Special thank you to https://github.com/akgunter/crt-royale-reshade for porting the CRT Royale to ReShade.

# How to use

> **PLEASE NOTE:** You can also import the mod manually by downloading the IRO from the [releases page](https://github.com/tsunamods-codes/reshade-crt-royale/releases) and import it via 7th Heaven manually

- Install ReShade from the Mod Manager General Setting window
- Install the mod from the catalog
- Enable the mod and enjoy!
